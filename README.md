# Ride A Pet Hub

สคริปต์ Roblox: บิน • ESP ไข่ทุกระดับ • ฟาร์มไข่อัตโนมัติ (เก็บ → กลับบ้านฝาก) • เดินเร็ว/กระโดดสูง • Anti-AFK • เมนู WindUI (มีปุ่มลอยสำหรับมือถือ)

## วิธีใช้

คัดลอกโค้ดบรรทัดเดียวนี้ไปวางใน executor แล้ว Execute:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ItsPvpMB/RideAPetHub/main/RideAPetHub.luau"))()
```

## ปุ่มลัด

- **RightShift** = เปิด/ปิดเมนู (ปิดเมนูจะมีปุ่มลอยบนจอ กดเปิดใหม่ได้ ลากย้ายได้)
- **F** = บิน (WASD ตามกล้อง, Space/Ctrl ขึ้น-ลง)
- **N** = ทะลุกำแพง

## ฟาร์มไข่อัตโนมัติ

1. เปิดเมนู → แท็บ "หน้าหลัก" → กด **▶ เริ่มฟาร์มไข่**
2. สคริปต์จะวาบไปเก็บไข่ → วาบกลับบ้านฝากเข้ารัง → วนต่อ (ถ้าเปิดวนซ้ำ)
3. ปรับระดับไข่/ความเร็ว/เวลาได้ในแท็บ "ฟาร์มไข่"
4. ถ้ารังเต็ม สคริปต์จะหยุดเอง + แจ้งเตือน (กันไข่ที่เก็บมาหมดเวลาแตก)
