# Ride A Pet Hub

สคริปต์ Roblox ครบวงจรในไฟล์เดียว: ฟาร์มไข่อัตโนมัติ • บิน • ESP ไข่ทุกระดับ • ฟักไข่ • ซื้อของ • Rebirth • Auto Rejoin • เมนู WindUI (มีปุ่มลอยสำหรับมือถือ)

## วิธีใช้

คัดลอกโค้ดบรรทัดเดียวนี้ไปวางใน executor แล้ว Execute:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ItsPvpMB/RideAPetHub/main/RideAPetHub.luau"))()
```

## ปุ่มลัด

- **RightShift** = เปิด/ปิดเมนู (ปิดเมนูจะมีปุ่มลอยบนจอ กดเปิดใหม่ได้ ลากย้ายได้)
- **F** = บิน (WASD ตามกล้อง, Space/Ctrl ขึ้น-ลง)
- **N** = ทะลุกำแพง

## ระบบอัตโนมัติ (สวิตช์เปิด/ปิดแยกแต่ละอันในแต่ละแท็บ)

- **🥚 ไข่** — เก็บไข่อัตโนมัติ (วาบไปเก็บ → กลับบ้านฝาก → รอบใหม่, เก็บได้แม้รังเต็ม) • เลือกระดับไข่ (Common→Ethereal) • เรียงตามความหายาก / **Luck สูงสุดก่อน** • ฟักไข่อัตโนมัติ • เปิดเรดาร์อัตโนมัติ • ESP ไข่ (+★Luck)
- **🐾 สัตว์เลี้ยง** — เก็บเงินจากสัตว์เลี้ยง • ให้อาหารอัตโนมัติ • จัดรังอัตโนมัติ
- **🛒 ร้านค้า** — ซื้อของอัตโนมัติเลือกไอเทมได้ (แยกร้าน Food/Gears, ไม่เลือก = ซื้อทุกอย่าง) • ปุ่มวาบไปร้าน
- **⚙️ อื่น ๆ** — ♻️ Rebirth อัตโนมัติ • 🔁 Auto Rejoin (โดนเตะกลับเข้าเกมเอง + รันสคริปต์ต่อ) • Anti-AFK

## หมายเหตุ

- รันหลังเข้าเกมแล้วเท่านั้น • ต้องต่อเน็ตครั้งแรกเพื่อโหลด UI
- รอบรับทุก executor ยอดนิยม (มือถือ/คอม) — ถ้า UI โหลดไม่ได้ ระบบอัตโนมัติยังทำงานอยู่
